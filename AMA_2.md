
### Adhikya Edammala: When do we use Grid and Flexbox?
- Flexbox → one direction layout
- Grid → rows and columns layout

### Allanki VV Manikanta Sai: What is the use of media queries?
Media queries make websites responsive for mobile/tablet/desktop.

### Arpit Yadav: How to change direction of flex items?
Use `flex-direction`.

```css
flex-direction: column;
```

### Boorle Sowmya Sri Lakshmi: What are pseudo classes and pseudo elements?
- Pseudo class → special state (`:hover`)
- Pseudo element → specific part (`::before`)

### Injamuri Arun Kumar: Difference between px and % units?
- `px` → fixed size
- `%` → relative size

### Kamparapu Lakshman: What is the use of DOCTYPE?
`DOCTYPE` tells browser the document type (HTML5).

```html
<!DOCTYPE html>
```

### M Harivardhan Reddy: What is an iframe?
`iframe` embeds another webpage inside a webpage.

### Md Musharaf: Difference between align-items and justify-content?
- `justify-content` → main axis
- `align-items` → cross axis

### Nayunipatruni Harsha Vardhan: What is the use of alt in image tag?
`alt` gives alternative text for images.

### Parlapalli Sulochana: What is align-self?
`align-self` aligns one flex item separately.
